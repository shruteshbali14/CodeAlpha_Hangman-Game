# Hangman Game

## Description
A simple Hangman Game developed using Python where players guess a hidden word one letter at a time within a limited number of attempts.

## Features
- Random word selection
- Letter-by-letter guessing
- Limited attempts
- Win and lose conditions

## Technology Used
- Python
- Random module

## How to Run
1. Open the project in VS Code or any Python IDE.
2. Run the `CodeAlpha_Hangmangame.py` file.
3. Enter a letter when prompted.
4. Continue guessing until you win or run out of attempts.

## Author
Developed during the CodeAlpha Python Programming Internship.

## Setup:  
  - A word or phrase is chosen (often by one player or the computer).  
  - Each letter in the word is represented by a blank space (e.g., _ _ _ _ _ for "game").
    
## Example
Word: HELLO  
Display: _ _ _ _ _  
Guesses:  
- "H" → H _ _ _ _  
- "E" → H E L _ _  
- "L" → H E L L _  
- "O" → H E L L O   (Win!)
